# Demo assets for VideoGenDoctor

## Contents

- `demo.mp4` — short test video (generated by `make_demo_video.py` if not present)
- `demo_shotir.json` — ShotIR v0.1 specification for the demo video
- `make_demo_video.py` — generates `demo.mp4` using ffmpeg test source (cross-platform)
	- `make_demo_video.sh` remains for convenience on bash-based systems.

## Quick start

```bash
# Generate demo video (requires ffmpeg)
python assets/demo/make_demo_video.py

# Run full pipeline
make demo
```

## demo_shotir.json schema
See `packages/videoeval/videoeval/report/schema.json` for the full report schema.
The ShotIR spec follows the format expected by the VideoEval pipeline.
