Title: VideoGenDoctor: Evidence-Grounded Failure Diagnosis and Actionable Repair for Controllable Video Generation

[PASTE FULL MANUSCRIPT HERE]

### Motivation
Controllable video generation (e.g., ShotIR-driven pipelines) increasingly relies on
complex multi-shot, multi-character, multi-prop specifications. Despite recent advances in
diffusion-based video generators, practitioners still face systematic, hard-to-diagnose failures:
identity drift across shots, camera deviation from plan, missing/misplaced props, temporal
jitter at segment boundaries, and style inconsistency. Existing evaluation frameworks
return aggregate quality scores with no failure localization, no root-cause codes, and no
actionable repair path — leaving engineers with no systematic recourse.

### Proposed System
VideoGenDoctor is a closed-loop diagnosis-and-repair system that:
1. Ingests a generated video + optional ShotIR specification.
2. Segments and embeds frames (OpenCLIP / EVA-CLIP).
3. Runs a Stage-1 rule engine to emit top-K failure codes with evidence spans.
4. Optionally routes candidate segments to a Stage-2 VLM judge for fine-grained Q&A.
5. Compiles a structured patch (shotir.diff.json or rerender_plan.json).
6. Supports closed-loop rerenders: diagnose -> patch -> rerender -> re-diagnose.
